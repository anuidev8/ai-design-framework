# AI Design Framework (skill stub)

When invoked:

1. Read the project’s `soul.md` or create one from `templates/soul.md`.
2. Follow `docs/02-workflow-steps.md` in order.
3. Prefer `prompts/master-orchestrator.md` if the user wants a full autonomous run.
4. For variants only, use `prompts/one-shot-variants.md`.
5. For implementation after lock, use `prompts/build-prototype.md`.

Reference mindset: https://www.youtube.com/watch?v=VbqaL_eHhKY (`soul.md`, mood boards, one-shot many variants, agents as builders).

Install: copy this folder into your agent skills directory (Cursor / Codex) and point `description` at your team’s conventions.
