# Design inspiration pack (optional path)

Topic slug example: `volumetric-voice-ai-factory`

```
design-inspiration/<topic>/
  refs/           # 3–6 browser screenshots
  references/     # curated links
  patterns/       # layout / interaction / visual + keep/change/avoid
  direction/      # one-paragraph design direction
  checklists/     # 10–20 implementation rules
  ai-manifest.json
```

Use when you want a **topic research pack** before Figma/code — complementary to Pinterest mood boards.
