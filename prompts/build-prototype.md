# Build prototype prompt

Use after a direction is locked.

---

Build the first interactive prototype using `soul.md` as the source of truth.

Also use:

- `design-system.md`
- `specs/feature-specs.json`
- mood board notes for taste only

Locked decisions (fill these):

- Selected direction: [NAME]
- Language: [en]
- Navigation model: [one-screen / scroll / …]
- Motion: [library or CSS]
- CTA: [label + URL placeholder]

Goal: a polished prototype that proves the story and interaction — not a brochure of services.

Rules:

- Follow soul UI principles and non-goals
- Implement the state machine from specs
- Do not invent a new visual theme
- First viewport = one composition
- Prefer real interaction over decorative chrome

Deliver:

1. Working UI for all listed states
2. Short note of what was simulated vs real
3. What to polish next
